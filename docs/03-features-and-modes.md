# 功能范围与模式设计

## 1. 功能对齐 Clash（MVP 必做）

| 能力 | 说明 |
|------|------|
| 配置导入 | 本地 JSON；后续 URL 订阅 |
| 连接开关 | 一键 Connect / Disconnect |
| 代理模式 | Rule / Global / Direct（经 clash_api 或等价） |
| 出站选择 | Selector / URLTest 等与配置一致的节点切换 |
| TUN | 可开关；与模式联动 |
| 混合端口 | mixed inbound（如 `127.0.0.1:1080`） |
| 日志 | 级别可调、可过滤 |
| 延迟测试 | 对出站测活 |
| 状态总览 | 当前模式、TUN、DNS、冲突告警 |

## 2. 配置与界面（复刻 sing-box / SFM 气质）

- **配置**：用户基线保持 sing-box JSON；应用只追加「模式补丁」块或旁路 patch 文件，避免改到用户看不懂。
- **界面**：左侧配置/模式，主区节点与规则状态，底区日志与健康告警——信息架构靠近 SFM，文案简洁。
- **不强制**第一期做完整可视化规则编辑器；提供 JSON 编辑 + 校验即可。

## 3. 办公模式（Office Mode）

### 3.1 用户怎么用

1. 公司准入 / 公司 VPN 隧道 已连接（或必须常驻）。
2. 打开本应用 → 选择配置 → 点 **办公模式** → Connect。
3. 正常使用：OA/内网/公司站点无感；需要上的外网服务按规则走代理。
4. `git push`（GitHub SSH）应稳定，不因开代理而间歇失败。

### 3.2 产品策略

- **共存优先**：不当系统唯一总网关；避免与公司隧道抢大段路由 / 默认路由（除非用户显式切出国模式）。
- **少抢 DNS**：不在办公模式下强行制造「全局干净 DNS」幻觉；发现脏 DNS 时**提示**并自动保护关键直连。
- **关键应用保直连**：GitHub / `ssh` / `git` 等默认直连（走公司可达路径，例如污染后的 `100.12.0.0/8` 仅公司侧可达的情况）。
- **可预期**：模式切换可逆；断开应用应卸下补丁相关路由影响（在平台能力范围内）。

### 3.3 期望效果

| 流量 | 办公模式下的去向 |
|------|------------------|
| 公司内网 / OA / 微信企业等 | 直连（公司隧道） |
| 用户点名代理的域名（Google、ChatGPT 等） | 代理出国 |
| GitHub SSH / git | **直连**（默认策略，可改） |
| 未匹配 | 直连或配置的 `final`（办公预设偏向 direct，避免误送污染 IP 进 Trojan） |

### 3.4 实现要点（模式补丁）

- 在 `geosite-github → proxy` 等规则**之前**插入：`github.com` / `ssh.github.com`、进程 `ssh`/`git` → `direct`。
- `strict_route`：办公模式倾向 `false`（减少强行盖路由）。
- TUN：可开，但 HealthProbe 若发现双 TUN，展示告警：「公司隧道共存中，已启用办公保护」。
- 不在办公模式把 Clash Mode 默认打成 Global。

## 4. 出国模式（Abroad Mode）

### 4.1 用户怎么用

1. **尽量先断开**公司 VPN 隧道 / 仅保留身份（若公司策略允许）。
2. 点 **出国模式** → Connect。
3. 追求全局一致出国体验与干净 DNS。

### 4.2 产品策略

- **独占优先**：检测到公司 TUN / 公司 DNS 代理 仍在时，**强提示**「建议断开公司隧道」，可选择继续（降级为风险自担）。
- DNS：经 core 的 DoT/DoH（detour 代理），目标是 `dig ssh.github.com` 得到真实地址而非公司污染段。
- `strict_route`：可倾向 `true`（在用户确认无内网需求时）。
- GitHub：可走 `proxy`（因 DNS 应已干净；并用域名逻辑出站）。

### 4.3 期望效果

- 单 TUN（或公司隧道已让路）；DNS 干净；代理路径下 GitHub/`socks5h` 稳定。

## 5. 双 TUN / 脏 DNS 防护（两模式共用）

### 5.1 检测

- 多 utun + 特征地址（如同时存在公司侧网关与 sing-box `172.19.0.0/30`）。
- 系统 DNS 或探测域名落在已知污染/专用段（实现时可配置特征列表，当前环境经验值含 GitHub → `100.12.0.0/16` 一类）。
- `route get` 关键目的仍指向公司隧道网关。

### 5.2 动作

1. UI 告警（不静默）。
2. 办公模式：自动套「Git/SSH 直连」保护补丁。
3. 出国模式：阻断或二次确认后再连接。
4. 提供「复制诊断信息」便于支持（路由表摘要、DNS 结果、模式状态）。

## 6. 手动模式（Manual）

- 不套办公/出国补丁，完全按用户 JSON 运行（高级用户 / 对齐原版 SFM 行为）。
