# sing desktop — Tauri 2 (macOS)

Rust side of the desktop shell. Commands: `core_status`, `core_start`, `core_stop`,
`clash_get_proxies`, `clash_get_connections`, `clash_delay`, `validate_config`,
`health_classify`.

See `docs/05-macos-tauri.md` for Mac how-to. Windows skeleton deferred.

Cloud CI may lack a new enough rustc; prefer building on Mac with rustup.
